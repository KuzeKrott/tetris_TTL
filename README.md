# tetris_TTL
Игра тетрис, построенная на логических элементах TTL-логики, смоделированная в Multisim. Включает экран из 16-ти лампочек, кнопки вправо и влево, D-триггеры, мультиплексоры, счетчики, логические элементы. Читай README! Там интересно :)
## Зачем?
В ходе учёбы в техническом ВУЗе приходится решать нестандартные и интересные задачки. Этот курсовой проект по схемотехнике мог стать началом дипломной работы, но не был избран.
## Как установить?
Для запуска Вам потребуется Мультисим. Он будет лагать, но всё равно Вас впечатлит. [Скачать его можно вот так](https://multisim.su/)
## Как запустить?
Большая зелёная треугольная кнопка вверху экрана. Вам нужно навестись на область с лампочками - наш "экран". Ключи вправо и влево над ней - импровизированные кнопки, их нужно замыкать и сразу размыкать, они были выбраны, потому что частота тактового генератора меньше чем скорость работы обычной кнопки в симуляторе. Фигура одна, когда заканчивается игра начинает мигать верхняя линия. Чуть потренироваться и уже можно играть!
# Проектирование
В данной игре пользователь видит перед собой экран и две кнопки: сдвиг вправо, сдвиг влево. На экране появляется фигура, которая с течением времени сдвигается вниз, а пользователь имеет возможность сдвигать фигуру вправо или влево. Если фигуры, упав друг на друга, сложили линию в ряду, происходит сдвиг всего вниз на место сложившейся линии. Игра окончена, когда последняя фигура достигла верха экрана, верхняя линия начинает «моргать».
Задачей работы устройства является обеспечение появления на экране фигуры, её движение вниз, вправо и влево, обработка ситуации сложения фигур в линию.
## Разработка алгоритма
Без лишних слов, в основе всего алгоритм. Сначала была составлена схема алгоритма работы устройства. ![Схема алгоритма](https://github.com/KuzeKrott/tetris_TTL/blob/main/%D0%A1%D1%85%D0%B5%D0%BC%D0%B0%20%D0%B0%D0%BB%D0%B3%D0%BE%D1%80%D0%B8%D1%82%D0%BC%D0%B0.png)
## Разработка структурной схемы устройства
Для реализации данной игры требуются следующие блоки:
#### 1.	Элементы управления фигурой
Здесь находятся кнопки
#### 2.	Генератор
Создаётся основной тактовый импульс 0 для работы устройства
#### 3.	Расчёт зажигаемых лампочек
В данном блоке реализована формула, благодаря которой, по входным в неё значениям из «блока управления», на экране будет зажигаться одно из восьми возможных положений фигуры
#### 4.	Блок управления
Представляет собой мультиплексор, который получает данные из «Регистра предыдущего состояния» и «Регистра следующего состояния», а также счётчик, создающий новый тактовый импульс 1 для работы остальной части схемы, который также создает разрешающий вход на мультиплексор. Поскольку разрешающий вход может быть 0 или 1, он будет также использован и в качестве входа на матрицу Д-триггеров. Таким образом, если он равен 0, то старые значения (вход мультиплексора 0) положения фигуры будут гаситься (подаётся 0), а новые (вход мультиплексора 1) – зажигаться (подаётся 1). 
```
N=0 => old  |  reset
N=1 => new  |  set
```
И разумеется, счётчик отсчитывает такты до 4х: первые два гасят старые лампочки, вторые два зажигают новые.
#### 5.	Расчёт следующего состояния
В данном блоке реализована формула, аргументами которой являются положение нынешнего состояния фигуры из блока «Регистр следующего состояния», данные с кнопок вправо/влево, а также данные о положении фигур друг относительно друга (реализовано по составленному графу логики движения фигур)
#### 6.	Регистр следующего состояния
Представляет собой три Д-триггера, хранящих информацию о нынешнем положении фигур (подсчитанных по формулам из блока «Расчёт следующего состояния»)
#### 7.	Фиксация фигуры
Вспомогательный блок, который отключает ситуацию гашения уже упавшей фигуры. Поскольку логика сдвига фигуры вниз работает по принципу «гасит предыдущее положение, зажигает новое», необходимо ограничить гашение фигуры, которая считается упавшей
#### 8.	Регистр предыдущего состояния
Представляет собой три Д-триггера, хранящих информацию о предыдущем положении фигур. Получает информацию из блока «Фиксация фигуры»
#### 9.	Генератор для регистров
Данный блок необходим, чтобы значения состояний фигуры регистры считывали медленнее, чем зажигались новые фигуры. Здесь создаётся тактовый импульс 2 для регистров
#### 10. Матрица триггеров
Представляет собой 16 Д-триггеров с резисторами для каждой из лампочек экрана. Работает по тактовому импульсу 1. Необходима для возможности считывания информации на лампочках, а также удобства управления их работой
#### 11.	Удаление линии
Данный блок содержит 6 мультиплексоров – по 2 на каждый ряд, который может быть сложен в целую линию. Каждый мультиплексор содержит входы значений из лампочек рядом выше. Ситуация сдвига обрабатывается специальными переменными, идущими на разрешающий вход мультиплексоров, которые в свою очередь отслеживают, сложилась ли линия в ряду. При этом в каждом ряду один мультиплексор отвечает за вход «Д» триггеров, отвечая на логический вопрос «что будет на лампочке?», второй – за тактовый вход, отвечая на логический вопрос «где и когда это будет?». На вход Д идёт разрешающий вход из «блока управления». На тактовый вход идёт умноженные значения подсчитанной функции из блока «Расчёт зажигаемых лампочек» и тактового импульса 1. При этом, поскольку на входы мультиплексоров идут тактовые импульсы, стоит учесть возможность возникновения гонки сигналов, поэтому проверка на сложившийся ряд должна будет осуществляться по спадающему фронту тактовой частоты 1, а не по возрастающему, как работает остальная схема, что позволит гонки сигналов избежать
#### 12.	Экран
16 светодиодов, подключенных к земле и блоку матрицы триггеров

## Расчёт следующего значения
Для реализации необходимой функции был составлен граф переходов. Он представляет собой автомат Мили (каждое последующее состояние зависит от предыдущего). ![Граф переходов состояний](https://github.com/KuzeKrott/tetris_TTL/blob/main/%D0%93%D1%80%D0%B0%D1%84%20%D0%BF%D0%B5%D1%80%D0%B5%D1%85%D0%BE%D0%B4%D0%BE%D0%B2.png)
На рисунке далее представлено пояснение каждой переменной. Схематично в виде сетки 4 на 4 изображен экран и на нём обведены необходимые сочетания лампочек, а также все возможные положения фигуры. ![а) Все возможные положения фигуры; б) Интересующие комбинации лампочек в линии](https://github.com/KuzeKrott/tetris_TTL/blob/main/%D0%9F%D0%BE%D1%8F%D1%81%D0%BD%D0%B5%D0%BD%D0%B8%D1%8F%20%D0%BA%20%D0%BF%D0%B5%D1%80%D0%B5%D1%85%D0%BE%D0%B4%D0%B0%D0%BC.png)
В таблице далее представлено описание всех возможных переходов положения фигуры (составлена по автомату Мили). X0..X2 – предыдущее состояние, Y0..Y2 – следующее. ![Все возможные переходы положения фигуры](https://github.com/KuzeKrott/tetris_TTL/blob/main/%D0%92%D1%81%D0%B5%20%D0%B2%D0%BE%D0%B7%D0%BC%D0%BE%D0%B6%D0%BD%D1%8B%D0%B5%20%D0%BF%D0%B5%D1%80%D0%B5%D1%85%D0%BE%D0%B4%D1%8B%20%D0%BF%D0%BE%D0%BB%D0%BE%D0%B6%D0%B5%D0%BD%D0%B8%D1%8F%20%D1%84%D0%B8%D0%B3%D1%83%D1%80%D1%8B.png)
Поскольку для упрощения функций с таким числом переменных нецелесообразно использовать карты Карно, функции были выписаны и упрощены вручную:
```
Y0 = -x0 x1 -x2 (R -d ∨ -c) ∨ -x0 x1 x2 (L -c ∨ -d) ∨ x0 -x1 -x2 -h (R -f ∨ -e) ∨ x0 -x1 x2 (L -e ∨ -f);
Y1 = -x0 -x1 -x3 -g (-a ∨ R -b) ∨ x0 -x1-x2 -h (-e ∨ R -f) ∨ x0 -x1 x2 (L-e ∨ -f);
Y2 = -x0 -x1 -x2 R -b -g ∨ -x0 x1 -x2 R -d ∨ -x0 x1 x2 -d ∨ x0 -x1 -x2 R -f -h ∨ x0 -x1 x2 -f;
```
Функции Y0,Y1,Y2 и реализует блок «Расчёт следующего значения».
## Расчёт зажигаемых лампочек
Отдельную таблицу нужно составить для каждого светодиода – значения, в соответствии с которыми загораются фигуры на лампочках. ![Значения светодиодов](https://github.com/KuzeKrott/tetris_TTL/blob/main/%D0%97%D0%BD%D0%B0%D1%87%D0%B5%D0%BD%D0%B8%D1%8F%20%D1%81%D0%B2%D0%B5%D1%82%D0%BE%D0%B4%D0%B8%D0%BE%D0%B4%D0%BE%D0%B2.png)
Тут также для упрощения функций с таким числом переменных нецелесообразно использовать карты Карно, функции были выписаны и упрощены вручную:
```
F0 = -x2 -x1 -x0
F1 = -x2 -x1
F2 = -x2 x1 -x0 ∨ -x2 -x1 x0 ∨ -x2 -x1 -x0
F3 = -x2 x0
F4 = -x2 x1 -x0
F5 = -x2 x1
F6 = -x2 x1 ∨ x2 -x1 -x0
F7 = x2 -x1 x0 ∨ -x2 x1 x0
F8 = x2 -x1 -x0
F9 = x2 -x1
F10 = x2 -x0 ∨ x2 -x1
F11 = x2 x0
F12 = x2 x1 -x0
F13 = x2 x1 
F14 = x2 x1
F15 = x2 x1 x0
```
Функции F0,F1,F2 и реализует блок «Расчёт зажигаемых лампочек».
